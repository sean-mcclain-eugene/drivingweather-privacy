# drivingweather-privacy

Source of the Driving Weather privacy policy, published at
https://sean-mcclain-eugene.github.io/drivingweather-privacy/

## Publish (Sean, manual; this hasn't been done)
1. Create the **public** repo `sean-mcclain-eugene/drivingweather-privacy`.
2. Commit `index.md` and `_config.yml` (and this README) to `main`.
3. Repo **Settings → Pages → Build and deployment**: Source "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After the first build (about a minute), open the URL above and check that the policy renders with the Minimal theme.
5. Use that URL in Play Console (App content → Privacy policy) and in the app's About screen (`AboutLinks.PRIVACY_POLICY_URL`).

When the app's data practices change, edit `index.md` and update the effective date.
